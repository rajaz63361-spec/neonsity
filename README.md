# NEON CITY

Браузерная песочница в стиле GTA на чистом JavaScript.

## Как запустить

Просто открой файл `index.html` в браузере. Всё.

## Управление

- **WASD** — ходить / рулить
- **Shift** — бег
- **Мышь + ЛКМ** — стрелять
- **E** — сесть/выйти из машины
- **Space** — ручник (дрифт)
- **1, 2, 3** — оружие
- **Tab / Q** — переключить персонажа
- **P** — пауза

## Читы

Зажми **правый Shift** и набери:
- `HEALTH` — лечение
- `GOD` — бессмертие
- `MONEY` — деньги
- `SPAWNCAR` — машина
- `EXPLODE` — взрыв
